## The idea in one dhaba

| Role | In the dhaba | In real work |
|---|---|---|
| Data Scientist | Checks the accounts: which dish will sell? | Finds insights in data |
| ML Engineer | Invents a new masala | Trains models |
| **AI Engineer** | Runs the whole dhaba with a ready masala | Builds apps on top of ready models, through an API |

Real jobs overlap. But most AI Engineer roles do not ask for a PhD; they look at skills and projects. That is exactly what the next 40 days build: **Python, LLM APIs, RAG, evals, agents, deploy.**
